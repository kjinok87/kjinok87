## Selected Work

### [Skill RTM](https://github.com/kjinok87/skill-rtm) · Public

프로젝트의 요구사항, 완료 기준, 구현·검증 근거를 요구사항 추적표(RTM)에 모으는 도구입니다. 요구사항별로 확인된 것과 추가 작업이 필요한 것을 파악할 수 있습니다.

- 완료 여부를 뒷받침하는 실행 근거를 연결하고, 근거가 부족한 요구사항은 추적표에 남깁니다.
- 남은 요구사항에는 스킬의 버전, 사용 권한, 실행 환경, 검증 이력을 확인해 필요한 최소 스킬을 추천합니다.
- 0.2.0 및 같은 라이선스를 적용하는 후속 버전은 비상업적 사용·공유만 허용합니다. [라이선스](https://github.com/kjinok87/skill-rtm/blob/main/LICENSE)

### 오늘이 (Oneuli) · Private

개발 목표와 완료 기준을 먼저 합의하고, 기능 단위로 계획·승인·구현·검증을 이어가는 Codex 스킬입니다. 요구사항에서 구현 결과와 시험 근거까지 연결해 변경이 최종 목표에 미치는 영향과 남은 확인 사항을 추적합니다.

## How I Work

- 착수할 때 각 요구사항에 완료를 판단할 기준을 붙입니다.
- 실행 결과와 발견한 문제를 해당 요구사항에 연결하고, 수정 뒤 무엇을 다시 확인했는지 기록합니다.
- AI가 제안한 변경과 사람이 승인한 결정을 각각 기록합니다.
