## Selected Work

### [Skill RTM](https://github.com/kjinok87/skill-rtm)

요구사항과 완료 기준을 작업 단위로 나눈 뒤, 확인된 결과와 사용할 수 있는 AI 스킬을 추적표에 연결하는 Python 도구입니다.

- 스킬의 버전, 사용 권한, 실행 환경, 시험 결과를 대조해 남은 작업에 필요한 스킬을 추천합니다.
- 근거가 부족한 후보와 연결할 스킬이 없는 요구사항을 표에 남깁니다.
- 0.2.0 및 동일한 라이선스를 적용하는 후속 버전은 비상업적 사용·공유만 허용합니다. [이용 조건](https://github.com/kjinok87/skill-rtm/blob/main/LICENSE)

### [PMO 실행 대시보드 MVP](https://www.gpters.org/nocode/post/we-created-pmo-execution)

AI 제안과 사람이 승인한 결정을 화면에서 구분하는 정적 HTML 대시보드입니다. 착수 가능, 자료 필요, 결정 대기 상태를 로드맵과 함께 표시하고 합성 데이터로 확인했습니다.

### [근거 장부 기반 AI-PMO-OS](https://www.gpters.org/nocode/post/connecting-evidence-conclusion-aipmoos)

검토 결론에서 어떤 요구사항과 원문을 근거로 삼았는지 되짚을 수 있도록 설계했습니다. 요구사항에서 실행 결과, 발견사항, 조치, 사람의 승인까지 이어지는 흐름을 정리했습니다.

### [클릭 가능한 HTML 목업](https://www.gpters.org/nocode/post/create-mockup-screen-explained)

말로 설명한 화면을 가상 내용으로 채운 단일 HTML 프로토타입으로 만들었습니다. 넓은 화면과 좁은 화면의 배치, 대표 조작에 따른 화면 상태를 확인했습니다.

## How I Work

> 요구사항 → 완료 기준 → 작은 구현 → 실행 근거 → 검토와 승인

- 시작할 때 각 요구사항에 완료를 판단할 기준을 붙입니다.
- 실행 결과를 해당 요구사항에 연결하고, 발견한 문제와 재확인 결과를 남깁니다.
- AI가 제안한 변경과 사람이 승인한 결정을 각각 기록합니다.
